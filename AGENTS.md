# Project collaboration

Read Documentation/PROJECT_SCOPE.md, Documentation/DESIGN_DECISIONS.md, and the
relevant implementation before making substantial changes.

Maintain Documentation/DESIGN_DECISIONS.md as a chronological design record at
Reagan's request. For meaningful design changes, append the local date/timezone,
problem, chosen approach, alternatives, rationale, implementation status, tests,
remaining uncertainty, and revisit triggers. Separate user-approved decisions from
proposals and software checks from headset evidence. Link superseding entries;
do not silently erase earlier reasoning or invent historical dates/commit IDs.

Preserve existing scene edits and raw session files. Do not infer that a successful
plot, nominal sample rate, or synthetic test proves headset validation. Run the
integrity validator before interpreting timing-dependent behavioral features.

Keep inferred body/cognitive state distinguishable from measured device poses.
